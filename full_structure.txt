84: (Normal) [align=None] [HAS_IMAGE] 1.1)Project Description(KutumbSetu)
85: (Normal) [align=None] [HAS_IMAGE] KutumbSetu is a secure community management platform designed to digitally transform the administration of community organizations, trusts, and social groups. Many communities still rely on paper registers, spreadsheets, and manual processes to manage donations, member records, receipts, announcements, and family information, resulting in inefficiency, data redundancy, and lack of transparency. The proposed system provides a centralized mobile application where administrators can manage donor records, generate digital receipts, maintain member directories, publish community updates, visualize donation analytics, and represent family relationships through an interactive family tree. The application also includes role-based access control to ensure secure and authorized data management. By digitizing community operations, KutumbSetu aims to improve transparency, simplify administration, strengthen communication, and provide an organized platform for community members. The project uses Flutter and Dart for mobile application development, Node.js and Express.js for backend services, and MongoDB for database management. The DevOps activities include maintaining the project on GitHub, installing Jenkins on Windows, testing the mobile application using an approved automation tool, creating a Docker image for the login/registration component with database connectivity, and automating software installation using Ansible or Chef.These activities demonstrate how version control, continuous integration concepts, automated testing, containerization and configuration management can support a more organized software development process.

187: (Heading 2) [align=None] [HAS_IMAGE] 4.4 Docker and Containerization
188: (Normal) [align=None] [HAS_IMAGE] Docker is a containerization platform that packages an application and its required dependencies into a consistent environment.
189: (Normal) [align=None] [HAS_IMAGE] A Docker image is a template used to create containers. A container is a running instance of an image.
190: (Normal) [align=None] [HAS_IMAGE] For this SLA, Docker is used to package the login/registration component or the relevant service that supports it. The resulting container should be tested to confirm that it starts correctly and can communicate with the configured database.
191: (Heading 2) [align=None] [HAS_IMAGE] 4.5 MongoDB and Database Connectivity
192: (Normal) [align=None] [HAS_IMAGE] MongoDB is a NoSQL document database that stores data in flexible, JSON-like documents. KutumbSetu uses MongoDB to store application data such as member profiles and other supported community records.
193: (Normal) [align=None] [HAS_IMAGE] The Node.js backend connects to MongoDB using an appropriate driver or ODM, such as the MongoDB Node.js driver or Mongoose.
194: (Normal) [align=None] [HAS_IMAGE] When a Docker container accesses MongoDB, the connection string must refer to a reachable database host. For example, localhost inside a container refers to that container itself, not automatically to the host computer. Docker networking or a suitable external database address must therefore be configured.
